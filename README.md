# HORROR RADAR — дэшборд

Лабораторная работа 2. Дэшборд по жанру хоррор: цены на игры, аниме,
фильмы и личная музыкальная статистика.

## Что подключено

| Источник | Что даёт | Ключ |
|---|---|---|
| AniList (GraphQL) | аниме жанра: рейтинги, годы, популярность | не нужен |
| CheapShark | живые цены и скидки, оценки Metacritic и Steam | не нужен |
| FreeToGame | бесплатные игры жанра, платформы | не нужен |
| iTunes Search | фильмы жанра: год, жанр, обложка | не нужен |
| OMDb | рейтинг IMDb для фильмов | нужен |
| Spotify | топы, история прослушиваний, плейлисты | вход через PKCE |

## Как запустить

Открыть `index.html` двойным кликом **не получится** — браузер запретит
запросы к данным со страницы, открытой как файл. Нужен локальный сервер:

- VS Code, расширение Live Server: правый клик по `index.html` → Open with Live Server.
- Или в папке проекта: `python -m http.server 5500`, затем открыть `http://127.0.0.1:5500/`.

## Настройка

Всё правится в `js/config.js`:

- `spotifyClientId` — уже вписан.
- `spotifyRedirect` — оставить пустым, подставится адрес текущей страницы.
  Этот же адрес должен быть вписан в настройках приложения на
  `developer.spotify.com`. Локально это `http://127.0.0.1:5500/`
  (слово `localhost` Spotify не принимает), на GitHub Pages — адрес
  опубликованной страницы. **Оба адреса надо добавить в настройках приложения.**
- `omdbKey` — вставить ключ с `omdbapi.com`. Без него фильмы покажутся,
  просто без оценок IMDb.
- `horrorTitles` — список франшиз, по которым спрашиваются цены.
  У CheapShark нет фильтра по жанру, поэтому жанр задаётся этим списком.

## Про Spotify и снимок данных

Spotify недоступен из некоторых сетей: сам API отвечает, а страница входа —
нет. Поэтому блок устроен с запасом.

1. Дома, с VPN: открыть дэшборд, нажать **войти в spotify**, разрешить доступ.
   Данные загрузятся живьём.
2. Нажать **сохранить снимок** — скачается `spotify-cache.json`.
3. Положить этот файл в папку `data/` и залить в репозиторий.

Теперь на любом компьютере, даже там, где Spotify заблокирован, блок покажет
сохранённые данные и честно напишет дату снимка. Остальные пять источников
работают везде и загружаются живьём.

В папке лежит `data/spotify-cache.example.json` — это только пример структуры,
не настоящие данные. Заменить его своим файлом с именем `spotify-cache.json`.

## Структура

```
index.html          разметка
css/style.css       оформление
js/config.js        ключи и настройки
js/api.js           запросы к пяти источникам
js/charts.js        графики на SVG, без библиотек
js/spotify.js       вход через PKCE и кэширование
js/app.js           сборка дэшборда и события
data/               снимок данных Spotify
```

## Что стоит знать про код

**Графики нарисованы вручную на SVG**, библиотеки не подключались. Цвета
подобраны не на глаз: проверены на светлоту, насыщенность и контраст к фону
не ниже 3:1. Все графики одноцветные, поэтому различать серии по цвету не
требуется — это важно для людей с нарушением цветовосприятия. Под каждым
графиком кнопка «показать данные» открывает те же числа таблицей.

**Источники загружаются независимо.** Каждый рисует свой блок, как только
ответит, и падение одного не ломает страницу. В строке состояния под шапкой
видно, кто ответил, кто нет.

**Сортировка таблицы** — по клику на заголовок столбца, повторный клик
переворачивает порядок.
